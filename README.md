# CIS Web Multimedia Hub

A central repository for projects and assignments completed for my CIS web and multimedia course.

## Purpose

This repository demonstrates my progress with Git, GitHub, web development, multimedia organization, and professional version-control practices.

## Repository Structure

- `projects/` — Course projects and assignments
- `docs/` — Documentation and required course evidence
- `assets/` — Images and shared multimedia resources

## Technologies and Tools

- Git
- GitHub
- Visual Studio Code
- HTML, CSS, and JavaScript

## Version-Control Workflow

Development work is completed on separate branches, committed using conventional commit messages, and merged into the `main` branch.
